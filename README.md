# 증명서 한곳에

다양한 공공기관, 교육기관, 민간기관에서 발급받을 수 있는 각종 증명서를 한 곳에서 쉽게 검색하고 발급 받을 수 있도록 안내하는 원스톱 포털 서비스입니다.

## 주요 기능

- **증명서 검색**: 증명서 이름으로 검색하여 필요한 증명서를 쉽게 찾을 수 있습니다.
- **카테고리별 분류**: 주민등록·가족관계, 부동산, 소득·세금, 교육, 고용·취업, 건강·의료 등 카테고리별로 증명서를 확인할 수 있습니다.
- **발급 정보 제공**: 각 증명서의 발급기관, 발급방법, 수수료 등 상세 정보를 제공합니다.
- **발급 사이트 연결**: 해당 증명서를 발급받을 수 있는 사이트로 바로 연결됩니다.

## 기술 스택

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome (아이콘)
- Google Fonts (Noto Sans KR)

## 프로젝트 구조

```
증명서_한곳에/

```

## 구현 내용

1. **반응형 웹 디자인**: 모바일, 태블릿, 데스크톱 등 다양한 디바이스에서 최적화된 화면을 제공합니다.
2. **검색 기능**: 증명서 이름, 카테고리, 설명 등으로 검색 가능합니다.
3. **카테고리별 표시**: 카테고리를 클릭하면 해당 카테고리의 증명서 목록을 볼 수 있습니다.
4. **상세 정보 제공**: 각 증명서의 발급기관, 발급방법, 수수료 등 상세 정보를 제공합니다.

## 시작하기

1. 저장소를 클론합니다.
   ```
   git clone https://github.com/yourusername/certificate-portal.git
   ```

2. 웹 브라우저에서 index.html 파일을 엽니다.
